# A14: Controlled recovery of real Rat7M motion capture

This endpoint imputes a seven-frame gap in measured HeadF coordinates. The underlying trajectories are **real motion-capture measurements**, not generated poses or estimated video keypoints. The mask is synthetic and explicitly controlled. It tests a small, well-observed head/spine subset and cannot establish robustness to naturally missing limbs or raw-video occlusion. It is a custom benchmark derived from the DISK data release, not the original DISK paper protocol.

Frozen selection before model generation: from all seven mocap recordings, use subjects1–3 for training and subjects4–5 for test; recordings from an animal never cross the split. Select six consistently named landmarks in release order: HeadF, HeadB, HeadL, SpineF, SpineM, SpineL. Take 31-frame windows starting0,60,120,...; discard a window if any of its 558 target coordinates is nonfinite. Retain gap/selection counts. Mask only HeadF's xyz on window frames12–18. Do not interpolate, smooth or estimate any target before masking. Windows are nonoverlapping and separated by29 unused frames. All masks identical; no test-label-dependent hyperparameter selection. Complete-window selection restricts the evaluation distribution to valid mocap periods and may favor simpler behavior.

Input and output shape `(N,31,18)`, with each frame `[HeadF_xyz,HeadB_xyz,HeadL_xyz,SpineF_xyz,SpineM_xyz,SpineL_xyz]`. Inputs have NaNs only at masked xyz; targets contain measured full arrays. Metric: RMSE over finite target entries at exactly the missing-input mask; observed entries are not scored. Secondary per-subject RMSE and mean Euclidean error per masked 3D point. Native motion-capture coordinate units are retained; physical unit metadata is not independently confirmed by the downloaded MAT schema, so no unverified conversion is applied. Published Rat7M sampling is30Hz.

Reference baseline: linear interpolation separately within each window and coordinate, using visible flanking measurements. This is a matched conventional imputation reference, not a trained DISK reproduction or specialist SOTA. All model submissions receive identical training examples. No nonlinear estimation of a test target is done in adapter preprocessing. Only two held-out animals are available; report descriptive results, not neuron/frame-based significance.

Data: [DISK concept DOI](https://doi.org/10.5281/zenodo.15800034), pinned [version18405201](https://zenodo.org/records/18405201) (CC BY4.0), file `rat7M_raw_data.zip`; [Rat7M original collection v3](https://doi.org/10.6084/m9.figshare.c.5295370.v3); [DANNCE/Rat7M paper](https://www.nature.com/articles/s41592-021-01106-6); [DISK paper](https://www.nature.com/articles/s41592-025-02893-y). Cite both dataset creators and redistribution record. Raw recordings remain ignored cache; checksum manifests track provenance.
