# Cognitive parameter recovery mini-benchmark — M04 v1

Frozen before model generation or scoring, 30 October 2026. A new synthetic wrapper motivated by Wilson & Collins (2019), https://doi.org/10.7554/eLife.49547. It is not their official benchmark or a biological dataset.

Scientific endpoint: recover learning rate alpha and inverse temperature beta from two-action reward-learning histories. Q starts [0.5,0.5]. Pre-choice p(a=1)=sigmoid(beta*(Q1-Q0)); after observed reward r, Q[a] += alpha*(r-Q[a]); no unchosen update, lapse or perseveration. Rewards Bernoulli, reversal every 60 trials between [0.8,0.2] and [0.2,0.8]. Generate 24 independent simulated agents, 240 trials each, seed 20261030, alpha uniform [0.1,0.9], beta uniform [0.5,8]. Keep generating parameters and seed out of model prompt; give equations, bounds and observed choices/rewards only. No training labels. Models return code estimate(choices,rewards) -> (n_agents,2). One no-tool generation/model, high reasoning, NumPy/SciPy/sklearn, deterministic, 180 seconds on one numerical thread for all agents. No feedback or repair.

Primary loss: mean across agents and two parameters of absolute error divided by allowed parameter ranges (alpha 0.98, beta 9.9). Bounds for all fits: alpha [.01,.99], beta [.1,10]. Secondary: mean negative log probability per observed trial (descriptive in-sample fit, not held-out generalization). Also store per-agent errors. Specialist mathematical reference: correctly specified maximum-likelihood fit using a deterministic 16x24 grid followed by L-BFGS-B refinement from four best starts; report optimization diagnostics. It is a locally reproduced fitting routine, not a literature SOTA claim. Constant midpoint baseline [.5,5.05]. Fit quality and parameter error can disagree under finite samples; this is an identifiability sanity check, not proof of cognitive mechanism discovery. No population-neuroscience claim from simulated agents.

Scoring scripts may see hidden truth after code is frozen. General programs are statically checked for prohibited imports/I/O but AST checking is not a security sandbox. Only reviewed generated programs are executed. No arbitrary external contributions should be run through this research harness.
