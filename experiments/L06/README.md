A likelihood-informed posterior-sampling interface on all ten original sbibm observations. Known likelihood and prior; hidden reference samples are scorer-only. Generated samplers and two fixed numerical references each return 10,000 ten-dimensional draws per observation. This synthetic task is not the original simulator-only SBI leaderboard.
