# Post-hoc aligned specialist reference

This reference was specified on 2026-10-30 after the original Sol6 balanced accuracy (about 0.7184) and the unaligned pyRiemann tangent-SVM result (about 0.6123) had been observed. It is an exploratory, post-hoc comparison, not a preregistered experiment or a SOTA claim. The [frozen config](specialist-aligned-config.json) records the complete grid and selection policy before this aligned reference's first predictions or test score. No second configuration may be selected from its test performance. The original H01 arrays, split, labels and model programs remain unchanged.

The reference uses Riemannian covariance recentering, an established subject/domain alignment operation from [Zanini et al., *Transfer Learning: A Riemannian Geometry Framework With Applications to Brain–Computer Interfaces*, IEEE TBME 65(5),1107–1116 (2018)](https://hal.science/hal-01923278), as implemented by [pyRiemann 0.12 TLCenter](https://pyriemann.readthedocs.io/en/v0.12/generated/pyriemann.transfer.TLCenter.html). The versioned official API and installed source were inspected; the author archive was access-blocked when checked. This reproduces the centering operation with a standard tangent-space linear SVM, not the complete published evaluation or its reported performance. The software version is pinned. pyRiemann 0.13's newer transductive API is not used.

Each epoch is filtered independently, temporally demeaned and converted to an OAS covariance, trace-normalized before alignment. TLCenter estimates a separate Riemannian mean for each subject and whitens that subject's covariances around the identity. Constant dummy class labels are used in domain encoding; true class labels are unnecessary for centering. Five training-only leave-one-subject folds select one of the frozen three bands and three SVM C values by mean per-subject balanced accuracy. Inside each fold the held-out training subject is centered using its own unlabeled batch; tangent reference, feature scaling and supervised classifier are fit on the four source training subjects only. Source centering depends only on each source subject's own data. Final test inputs are accessed only for the chosen band after selection, centered independently for subjects 6–8, and classified by the refit training model. No test labels are loaded by the runner or passed to the method. Ordinary SVM predictions are used, with no assumed test-class proportions or median-rank decision threshold.

Full unlabeled validation/test subject batches may be used for centering. This is offline transductive decoding with zero-phase within-epoch filtering; it makes **no causal, streaming or online BCI claim**. It matches the availability of unlabeled batch adaptation in Sol6's submission, which inferred 45-trial subject blocks and applied subject centering plus median score thresholding. It does not reproduce that submission. The specialist receives explicit subject-group IDs and pyRiemann, unlike the generated models' three-array, general-library interface. It also receives a separately disclosed 600-second cap versus the models' 180 seconds. This comparison is neither equal-information nor equal-development-effort.

Unsupervised centering can depend on target class composition; no target class counts, balance corrections or labels are supplied. There are only three fixed test participants, so any observed result is evidence for this small slice, not a population-wide superiority statement. Preserve this aligned reference alongside the unaligned reference and original CSP baseline; do not silently replace the baseline or report only the strongest score.

Run from the workspace with `PYTHONPATH=work/sleep-deps:work/pilot-deps`, `OPENBLAS_NUM_THREADS=1`, `OMP_NUM_THREADS=1` and the bundled Python. The runner saves all training-only CV scores, selected parameters, prediction/config/code/data hashes, package versions, timing and a before/after unchanged-data check. Prediction generation is separate from external test scoring.
