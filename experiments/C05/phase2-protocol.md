# Frozen-program transfer audit — C05 phase 2

Frozen before acquiring or scoring datasets 2–5, 30 October 2026. This is an exploratory protocol recorded in Git, not an external preregistration.

Reuse the three unchanged pilot-v1 programs on original Spikefinder preparations 2–5. Fit each program afresh to that preparation’s training neurons. There is no model reprompting, test-label feedback, code editing, task-specific manual tuning, or model selection. Dataset 1 was previously inspected and is a development/pilot result; datasets 2–5 are a subsequent transfer audit. These are four further slices of **one benchmark**, not four new task families. The original prompt described dataset 1’s dimensions, so this tests the frozen program’s shape/preparation portability rather than identical fresh per-dataset model prompting. Failures remain in the table. Primary metric: official 40-ms binned per-neuron Pearson, median within a preparation. Also retain means and every cell. Report preparation-equal summaries descriptively; no biological population CI without animal IDs.

Use a fourth cost-oriented model, GPT-6 Luna, once with the exact original C05 prompt at high reasoning, no tools and the same code interface. It is a capacity-tier contrast, not an older chronological Sol generation. Keep Luna off the Sol generation trajectory. One numerical thread and 180-second wall limit per estimator; approximate memory request is not enforced. Copy exact code, hash prompt/code/inputs, save predictions, scoring results, failures and provenance.

Compare to archived same-slice predictions with complete cells and to OASIS default AR1. The inspected archive includes Deneux, Friedrich, Speiser and Rupprecht; best-of-these is an explicitly limited archive reference, never current global SOTA. Their original training/tuning budgets differ. Use performance-only reference deltas, not a matched-budget general-vs-specialist causal claim.
