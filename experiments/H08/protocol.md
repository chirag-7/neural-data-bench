# H08 — Sleep-EDF fixed overnight window

Custom participant-held-out sleep-staging diagnostic derived from [Sleep-EDF Expanded1.0.0](https://physionet.org/content/sleep-edfx/1.0.0/), DOI[10.13026/C2X676](https://doi.org/10.13026/C2X676), ODC-By1.0. Technician R&K hypnograms are independent labels, not YASA-generated truth. All16selected source files match the publisher SHA256SUMS. Use first night of subjectsSC400–SC407, five train and three test. Selection was fixed before any model scores, not a representative sample or official SleepEDF20split.

Inputs are raw calibrated EEG Fpz-Cz at100Hz in microvolts. Each subject/night supplies1440consecutive30second epochs of3000samples. Select the12hour clock window starting20:00, rounded up to the next30sboundary of the source recording, ending about08:00. This rule uses EDF recording clocks and never hypnogram labels, avoiding label-dependent wake trimming. No EEG filtering, resampling or artifact rejection is introduced. All selected recordings cover the window. The paired PSG/hypnogram EDF startdate/time bytes are exactly equal; MNEreturns relative annotation onsets with orig_timeNone. An initial overlystrict orig_time assertion was replaced by explicit matching source header timestamps before protocol/model freeze.

Map Wake0,N1=1,N2=2,N3=3(R&Kstages3and4merged),REM4. Movement/unscored/cross-annotation epochs are-1, ignored when fitting and scoring; they remain in signal context. A label is assigned only when an entire30sepoch lies within one expert annotation span. Primary pooled five-class macroF1(fixed labels0–4); secondary balancedaccuracy, accuracy and per-night macroF1. Nights/people are independent held-out units, not epochs. Three test subjects are too few for broad population claims.

`fit_predict(train_x,train_y,test_x)` receives shapes(5,1440,3000),(5,1440),(3,1440,3000), returns integerlabels(3,1440). Acausal within-night context and unlabeled night-level normalization are allowed; never join nights. General packages only, one frozen submission/model,180seconds/one numericalCPUthread,<240code lines, approximate4GBunenforced. No label feedback or program repair.

The conventional reference is fixed spectral/statistical features plus HistGradientBoostingClassifier trained only on five training nights. A separate stronger specialist is published [YASA](https://doi.org/10.7554/eLife.70092), package0.8.1, default pretrained EEG-only/no-demographic classifier. [Author training repository](https://github.com/raphaelvallat/yasa_classifier) lists NSRRcohorts(CCSHS,CFS,CHAT,HomePAP,MESA,MrOS,SHHS), distinct from this SleepEDFsource; provenance is declared rather than independently auditing every training record. Apply it to the exact three supplied12hour test windows, no additional EOG/EMG or metadata. YASAuses full-night features and temporal smoothing; the general programs have the same night context available. Specialist training/pretraining and fitting budget differ, so no matched-effort superiority claim or currentglobalSOTAclaim. Full checkpoints/hashes/packageversions and predictions retained.

This does not measure full-night clinical staging across disorders or the official2026challenge. SingleFpz-Cz derivation differs from YASA's preferred central derivation. Public data/pretraining contamination and exact hosted checkpoint identities remain unresolved. All failures remain in the results.
