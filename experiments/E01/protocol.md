# E01: Real neural population co-smoothing diagnostic

Data: macaque Jenkins, MC_Maze_Small, delayed reaching, dorsal premotor and primary motor cortex. Pin [DANDI000140 version0.220113.0408](https://doi.org/10.48324/dandi.000140/0.220113.0408), CC BY4.0. Raw train/test NWB assets are immutable IDs in data-manifest.json. Test groundtruth was [released by NLB in January2026](https://github.com/neurallatents/nlb_tools), pinned commit42f8410b88e12db136910fa2f888b025ea0aa2ae, Git LFS `data/eval_data_test.h5`, group `mc_maze_small_20/eval_spikes_heldout`.

Use unmodified official nlb_tools NWBDataset.resample(20), make_train_input_tensors and make_eval_input_tensors with default MC_Maze_Small alignment (movement onset,-250to+450ms). Inputs are107held-in neurons and targets35held-out neurons for35bins per trial. Combine the original train and validation labels for a99trial training pool and evaluate on100official test trials. The default official reader retains no valid aligned timepoints for final training trial199; exclusion is logged. This explicit deviation and bounded supervised readout task mean **these results are a custom diagnostic, not an official full NLB leaderboard submission**. No submission uses test targets for fitting, architecture selection, preprocessing or prompt construction. All35target neurons are observed in training trials but withheld from test input, which is the intended co-smoothing information pattern.

This is held-out-trial prediction from the **same animal and session**, not unseen-animal transfer. Trial windows retain the official split; no random bin-level train/test split. Temporal context is allowed within each trial. Code-generated models receive `(train_x,train_y,test_x)` and output finite nonnegative expected spike counts per20ms bin `(N,35,35)`; counts must not be interpreted as Hz. No behavior covariates or trial-condition labels are provided.

Primary metric is the exact official NLB Poisson bits/spike formula: `(NLL_null-NLL_model)/(sum_spikes*ln2)`. The null is each neuron's constant **evaluation-set mean**, used only inside the fixed scorer to normalize prediction likelihood; it is not available to the fitted model. Poisson NLL includes log-factorials; zero predicted rates become1e-9; negative or nonfinite outputs fail. The metric can be negative. An evaluation-mean oracle yields0bydefinition, not a fitted baseline. A train-mean constant baseline can be scored separately and can have a negative primary score. Independent checks compare the local scorer to vendored official `bits_per_spike`.

Reference: Gaussian smoothing sigma1bin (20ms), separately within each trial; one fixed Ridge(alpha100) population-to-neuron readout; predicted counts clipped below at1e-6. It uses the same training labels and inputs. It is a conventional matched baseline, **not current specialist SOTA**; published LFADS/NDT/GPFA scores use broader modelling/budget/official protocols and must not be transplanted.

Retain trials as resampling units; all samples come from one macaque/session, so no population-level inference from35neurons×35bins×100trials. One code-generation sample/model cannot establish general capability or scaling. Compare primary scores descriptively and label scope narrowly.

Sources: [NLB task definitions](https://neurallatents.github.io/), [dataset descriptions](https://neurallatents.github.io/datasets), [NLB paper](https://arxiv.org/abs/2109.04463), [pinned nlb_tools](https://github.com/neurallatents/nlb_tools/tree/42f8410b88e12db136910fa2f888b025ea0aa2ae). Vendored source files' Git blob hashes are verified against that commit; MIT license retained. Reader dependencies are recorded separately, not vendored.
