# Archived VASSI specialist reference

The primary comparator is **vassi-run-00**, selected as the lowest numeric archived run before any rescoring. Its macro F1 on the unchanged A09 four-class centers is **0.8695177327504425**. All 20 archived runs are retained: descriptive median 0.8689440631758837, range 0.866711197217867–0.8702791972840422. The maximum is a range endpoint, never the selected reference. Run variation is not an uncertainty estimate across animals or independent datasets.

Source: Nührenberg, Paul, *Supplementary data for the vassi Python package*, [Edmond DOI 10.17617/3.3R0QYI](https://doi.org/10.17617/3.3R0QYI), version 1.0, CC BY 4.0; file 315313, `examples/CALMS21/results.h5`, 150,340,192 bytes. The publisher MD5 matches `242beccb757da2573c7879db66908ec6`; SHA256 is `dca04622d09d11c69f8054970f73f4f952473c91884ab23b16bd9175857e8bf1`. Original CalMS21 attribution: Sun and colleagues, [DOI 10.22002/D1.1991](https://doi.org/10.22002/D1.1991). The raw archive remains in ignored cache; derived predictions at scored centers are retained with attribution.

`../specialized_reference.py` reads saved predictions and rescores them. It does not train a classifier, retrain Sol programs, alter original annotations, tune thresholds or select the best test run. `.predictions.npz` files contain predicted integer classes and exact frozen test-unit IDs. `.scores.json` files contain the common four-class macro F1, secondary foreground F1 and balanced accuracy, confusion matrix and per-recording descriptive values. `summary.json` centralizes these scores and provenance.

Alignment was independently checked against the original official CalMS21 JSON: all 19 sequence lengths/order and all 262,107 original frame labels match every archived run’s true-label vector. VASSI’s converter defines timestamps as zero-based `np.arange`; no one-frame offset or nearest-frame matching was applied. The exact 26,162 A09 centers, 15, 25, 35, …, have identical labels and IDs. See `../specialist-alignment.json` and `../verify_specialist_alignment.py`.

**Unequal information and optimization budget:** archived VASSI uses 201 hand-designed spatiotemporal pose features, includes temporal steps up to 30 frames plus optimized postprocessing windows, and trains XGBoost with 1,000 trees using all training attack/mount frames and sampled investigation/other frames (up to 30,000 each). Postprocessing is chosen by five-fold prediction on the training dataset, with 20 optimization runs and 2,000 Optuna trials per run. Our Sol T3 programs receive only 3 Hz centers with seven raw-coordinate offsets and a 180-second execution budget. Test centers, labels and metric are matched; training rows, feature engineering, temporal context, tuning and computation are not. These archived specialist scores support a practical pipeline comparison, **not strict equal-budget superiority counts or a current-SOTA claim**.

Primary documentation: [training/evaluation and archive format](https://vassi.readthedocs.io/en/latest/source/results_and_figures-mice.html), [training-only postprocessing selection](https://vassi.readthedocs.io/en/latest/source/postprocessing_parameters.html), [source repository](https://github.com/pnuehrenberg/vassi). The five provenance snippets in `source/` exactly match the archived version 1.0 source ZIP (Edmond file 315709), as well as pinned GitHub commit `9fdf7111ae11160dbfffbd7a29d1e20a0f8c1886`; their MIT license is retained. `source-manifest.json` records these checks.
