# A09: CalMS21 social behavior, fixed temporal slice

This real-data endpoint measures code-generated supervised classification from **estimated pose inputs** to **human expert behavior labels**. It does not evaluate raw-video perception or pose-estimation accuracy. It is a custom compute-bounded 3 Hz subsample of Task1, not an official leaderboard submission.

Frozen before model generation: use all official training and test recordings; sample centers 15,25,35,... stopping at least 15 frames before the end. At 30 Hz, seven offsets [-15,-5,-1,0,1,5,15] provide a one-second temporal context; each has 28 coordinates in original order (mouse, x/y, landmark). Train and test recordings are separated by animal identity in the dataset readme. Windows never cross recordings. No labels or test-performance information affect sampling. Model input shape is (examples,7,28), output integer class per center. Classes: 0 attack, 1 investigation, 2 mount, 3 other; resident mouse initiates behavior unless specified by source.

Primary metric: pooled macro F1 with fixed labels [0,1,2,3], zero_division=0. Secondary balanced accuracy, class-wise F1 and per-recording metrics. Frames and windows are correlated; they are not independent animals. Bootstrap at recording level only if uncertainty is reported; small recording counts limit generality. No claim of an official full-frame score or significance from a single generated program.

Baseline: fixed geometry-distance features and ExtraTrees supervised classifier using the same training examples; this is a reproduced classical reference, **not current specialist SOTA**. Original CalMS21 temporal convolutional/MARS/TREBA scores use other inputs or full-frame protocols and cannot be imported as matched scores.

Sources: [original data DOI 10.22002/D1.1991](https://doi.org/10.22002/D1.1991), [record](https://data.caltech.edu/records/s0vdx-0k302), [paper](https://arxiv.org/abs/2104.02710), [original paper data-use disclosure](https://pmc.ncbi.nlm.nih.gov/articles/PMC11067713/). Archived source-readme.md and source-record.json document exact release. **License discrepancy:** current repository API says CC BY 4.0, original paper says CC-BY-NC-SA 2.0. Raw data remain in ignored local cache; no raw redistribution.
