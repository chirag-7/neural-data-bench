# C06 preparation contract — CASCADE DS04

Prepared 31 October 2026, before any model generation or method execution. Parent review and a separate freeze are required. This is a custom native-rate animal-held-out endpoint, not the CASCADE paper's noise-resampled leave-one-neuron-out benchmark and not a leaderboard submission.

Use every released neuron and recording in `Ground_truth/DS04-OGB1-zf-pDp` at commit `1f9f98bf93b9b554ab68d6304aa365ab7c7ee34f`: 15 neuron files, 45 recordings, 81.66 minutes. Adult zebrafish explanted brain, OGB-1, posterior Dp; paired optical and juxtacellular electrical measurements. The original paper's table identifies 15 neurons and approximately 81 minutes, providing a coverage cross-check. These newly recorded zebrafish data are distinct from the mouse Spikefinder sources used for C05; exclude all CASCADE Theis/Spikefinder and X-* sources entirely.

Sort specimen keys by the filename's date/Fish combination, assign alternating keys to train/test. Train `190115_Fish2`, `190125_Fish1`: 7 neurons, 21 recordings, 37.83 minutes. Test `190116_Fish1`, `190301_Fish1`: 8 neurons, 24 recordings, 43.83 minutes. All recordings of a neuron remain together; no row or random-frame split. The date/Fish combination is an operational specimen identity inferred from publisher filenames; dates are distinct acute ex-vivo preparations, consistent with the methods. No extra specimen metadata was released. Two test animals support descriptive transfer evidence, not population-level confidence intervals. The split was selected without executing prediction methods or selecting cells by activity.

Input `train_x` shape `(21,3,900)`, test `(24,3,900)`. Each row is a complete recording. Channel 0 is publisher `fluo_mean` dF/F without extra normalization or added noise. Channel 1 is a binary valid-frame mask. Channel 2 is the median sampling interval in seconds, repeated over valid frames. Right padding in all channels is zero. Native sampling varies approximately 7.51–7.8125 Hz. Rows are separate recordings; never concatenate or smooth across them. Arbitrary offline/acausal context within a row is allowed. Training neuron/specimen row membership is supplied in metadata for grouped validation; it must not be treated as a biological predictor.

The target shape is `(N,900)`: nonnegative Gaussian-smoothed expected spike counts per native frame (not Hz). Convert `events_AP` from 0.1 ms ticks to seconds. Bin at midpoint edges around fluorescence timestamps, with endpoint half-interval extension. Smooth each recording independently with Gaussian sigma `0.2 / dt` samples, SciPy reflect boundaries and default truncation 4 sigma. This conserves each recording's counted spikes. Training padding is -1 and must be excluded. Test prediction padding is ignored; require all outputs finite and nonnegative. Return predictions already at this 200 ms target resolution; the scorer does not smooth a second time.

One source (`190115_Fish2_cellA`) has 900 fluorescence values but only 468 timestamps; discard the untimed tail exactly as the publisher `utils.py` loader does. Events outside valid timestamp support are excluded and explicitly counted in the manifest (56 events over the test recordings); these events have no corresponding optical input. No recording is excluded, no activity-based crop/filter is used, and no fluorescence resampling, simulated spikes or pseudo-ground-truth is introduced.

Primary metric: Pearson correlation per neuron, concatenating only the already independently smoothed segments from that neuron; average neurons equally within each animal, then average the two animals equally. Constant predictions receive correlation 0. A constant truth neuron also receives 0 (none is removed). Secondary per-neuron relative absolute error and relative signed bias use all valid frames and normalize by the truth spike sum; report per-animal and per-neuron results. This grouping and native timing differ from the publication's pooled/resampled analyses, so numerical scores are not directly comparable. Correlation is amplitude insensitive; error and bias are necessary companion diagnostics.

Fixed reference code is OASIS AR1, default calcium-parameter estimation, penalty 1, optimize_g=0, and one positive global amplitude factor learned from training spike totals only. Smooth OASIS event estimates at 200 ms before scoring. Default OASIS is a recognized conventional specialist reference, not the best currently available CASCADE specialist. The released CASCADE global models include DS04 training data, so using them on this heldout split would contaminate the comparison. A stronger defensible reference requires retraining CASCADE with all test-specimen cells excluded, preserving the same native/noise contract, and reporting a separate specialist training budget. Archived paper aggregate scores and noise-2 parameter grids cannot be substituted for same-split predictions.

Three general submissions later: exact `gpt-5.6-sol`, `gpt-6-sol`, `gpt-6.1-sol`, high effort, one no-tool generation, `fit_predict(train_x,train_y,test_x,train_groups)`, fewer than 240 lines and 180 seconds on one numerical CPU thread. `train_groups` contains actual training specimen IDs, one per recording, for grouped validation only; IDs are not predictors. Test IDs and all test targets remain hidden. The fixed reference retains `baseline(train_x,train_y,test_x)`. The scorer must be called once on the canonical full test set and already returns neuron and animal summaries; do not re-call it on recording subsets. No model calls or real-slice prediction scores were made during preparation. No central registry or site change is included.

Rights: the upstream source repository includes GPL-3.0 and publicly distributes these data for research. No separate data-specific license statement was located. Preserve the original license and source attribution; retain raw arrays as a local ignored cache and publish acquisition scripts/manifests. This preparation does not assert a standalone permissive raw-data redistribution license. Parent review must keep that limitation visible.
