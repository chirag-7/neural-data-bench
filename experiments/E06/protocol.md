# E06 — ZAPBench causal 32-frame calcium forecasting

Prepared for parent review/freezing; no real evaluation method predictions or scores generated. This bounded diagnostic uses real larval zebrafish calcium recordings from one brain/session, source `240930_traces` (7,879 frames × 71,721 neurons). It does not test cross-animal generalization or a complete whole-brain leaderboard submission.

Original sources: [ZAPBench](https://google-research.github.io/zapbench/), [paper](https://arxiv.org/abs/2503.02618), [data and rights](https://zapbench-release.storage.googleapis.com/volumes/README.html), [pinned code](https://github.com/google-research/zapbench/tree/7347b3b21a3f332e281b774c945f1505dd966abf). Data CC BY 4.0. Credit Alex Bo-Yuan Chen/Ahrens lab HHMI Janelia for recordings, CellMap Project Team HHMI Janelia for segmentation annotations, and Google Research for alignment/segmentation/trace extraction. Source code Apache 2.0; local source license retained.

The fixed response-independent subset is neuron columns `arange(0,71721,280)[:256]`, original native trace order, not Rastermap ordering or neurons selected by variability/performance. Native normalized activity (df/f), no fitted normalization or clipping. The original trace columns represent segmentation labels `column+1`, per official data_utils. No physical frame interval is asserted; horizons are specified in recorded frames. Source object metadata contains generation IDs, publisher MD5/CRC32C and byte sizes. Exact selected-array SHA256 identifies the acquired numerical snapshot; acquisition can verify every source chunk against the publisher digest. Mutable Git main/bucket URLs are not treated as immutable releases.

Official condition offsets: `(0,649,2422,3078,3735,5047,5638,6623,7279,7879)`. Use official training conditions 0,1,2,4,5,6,7,8; exclude heldout condition3 (taxis) from this endpoint. For each condition remove one frame at both ends. From remaining length N, last floor(.2N) frames are test, preceding floor(.1N) validation, all earlier frames train. This reproduces pinned `get_condition_bounds` and `adjust_condition_bounds_for_split`. Validation targets are not supplied for fitting. The per-condition exact intervals are in data-manifest.json.

Each training example has64past frames and32subsequent target frames, all within its training interval, sampled at stride16. Each evaluation target is a nonoverlapping32frame block starting at the first official test target, stride32, through the last full block. Each test input is exactly its preceding64frames, consistent with official test context allowance. Some later test contexts naturally include previously observed test-period activity: this is repeated causal forecasting from observed history, not a single free-running forecast over the entire withheld period. No future frame of the same forecast may be used. Windows are independent examples for model access: **do not join, reorder, or borrow information across test rows**, infer adjacency, or fit any transform to pooled test windows. Overlapping test contexts do not make independent statistical units.

Interface `fit_predict(train_x,train_y,test_x,train_groups)` with `train_groups=None` (no stimulus/condition identities supplied) receives shapes `(272,64,256)`, `(272,32,256)`, `(43,64,256)` and returns finite native-unit activity `(len(test_x),32,256)` (43 rows on the main slice and 12 on the prespecified taxis slice). No stimulus covariates, condition labels, animal IDs, or test targets provided. Models may fit training-only regressors/temporal dynamics, use deterministic seeds, and validate with chronological training-only splits. Primary MSE across all windows,horizons,neurons (lower better), `mean((prediction-truth)**2)`. No variance weighting or target-dependent neuron selection. Negative calcium values are valid. Scorer uses float64. Per-condition MSE may be reported by evaluator from hidden group arrays; it must not be used for selecting a submission. Eight conditions all belong to one animal/session; no independent-neuron/window population inference.

Fixed specialist-task reference: official ZAPBench NLinear architecture, shared dense64→32temporal affine map, subtract last observed frame and restore afterward. Local NumPy implementation fits the same architecture analytically with fixed ridge1 and unpenalized bias, pooling training neuron/window pairs. This is an explicitly altered optimization/regularization reproduction, not official published NLinear weights, training budget, full-neuron result, or current strongest specialist. Official parameter-free MeanBaseline is also provided exactly as mean of input history repeated32times. Neither has been evaluated on real test targets before freeze.

No pretrained weights or specialist package calls. Parent pins prompt/adapter/data digests before dispatch.
