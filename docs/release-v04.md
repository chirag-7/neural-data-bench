# Release 0.4 — execution and admission report

This release completes a bounded expansion, not the requested final all-neuroscience study. It adds 12 executed protocols to the previous 2, yielding 14 task IDs,11 families,54 model-slice attempts and 120 total model/reference records. All 114 catalog entries have a dated admission assessment:14 measured,57 source-only candidates awaiting gates,43 deferred for stated access/rights/protocol/resource reasons. No unrun score is filled with zero and no dataset is declared bad without evidence.

## Main plan and scientific claim

Build a cross-domain evidence map, admit finite defensible task protocols, compare general and specialized approaches under explicit information/adaptation/resource tracks, then aggregate only compatible directional comparisons. The current measured track is T3 single-shot no-tool code synthesis plus local numerical fitting. General programs may implement domain statistical methods using NumPy/SciPy/sklearn. Native direct model capability, representations, fine-tuning, specialist-tool agents and open-weight/image/video/world models require separate tracks and remain unmeasured.

The contribution is an auditable cross-domain execution panel with archived predictions and explicit coverage gaps. It is not the first general-model neuroscience benchmark. [Closest prior work](prior-work.md) and [v 0.4 source reviews](../literature/v04-behavior-population-review.md) document substantial overlap, including SciVid's general-video evaluations and EEGAgentBench's tool-grounded EEG cases.

## What is dropped or deferred, and why

The 43 deferred entries are excluded from current execution, not permanently rejected. Some need validated raw-movie/3D/large-recording adapters and stronger GPU pipelines; some need simulator/action protocols or blinded statistical tasks; some have uncertain release, rights or evaluator dependencies. The 57 source-only candidates are plausible future work. Source-only review is not a successful download audit. Review records distinguish directly acquired files, attempted access and inherited source associations.

The Neuromatch RGC teaching file explicitly restricts research/publication without creator permission and was excluded; F04 instead uses the licensed Goldin 2022 release. DREAMS Expert 1 annotations cover only a fraction of the signal and require verified matching/terms. Unreleased/uncertain BrainAgent assets are not silently replaced by NeuroClaw or EEGAgentBench. These decisions are independent of model results.

## Coverage sufficiency

The 14-family map spans lab data production, behavior, raw electrical/optical signals, dynamics/encoding, BCI, human imaging, anatomy, cell/molecular assays, mechanistic inference, cognition/design/control and analysis workflows. Scientific-operation, truth, biological unit, transfer and resource axes expose gaps that a modality list hides. It is broad enough to organize a research program, not enough to certify no missing neuroscience task.

Unmeasured familiesB/G/J and unmeasured endpoints within other families remain substantial gaps: spike sorting/drift/collisions; online intracortical control; raw anatomy/histology/connectomics; full raw-image segmentation/pose; biological causal intervention and controlled model discovery; complete theory/simulation validation; clinical/prognostic, PET/SPECT, lifespan and chemical/autonomic tasks. No exhaustive full-literature/PRISMA review, independent human expert audit or universal coverage claim. A paper needs a bounded scope, formal expert coverage review and prospectively frozen confirmatory panel.

## Deviations and validity limits

K01 initial scorer wrongly rejected valid classes in single-class donor subgroups. Original failed harness logs are preserved; only the harness was corrected, unchanged programs rerun. N05 GPT-5.6 remains a genuine model-program failure. C05 GPT-5.6 format deviation remains visible. A14 windows remain correlated within rats despite independent computation. H01/I07 some programs infer subject block structure and use unlabeled input adaptation or different inner folds; this is not matched inner-procedure information. See the frozen prompts and programs.

Wall limit 180 seconds and one numerical thread; approximate 4GBrequest is not enforced. Parent process is not a hardened arbitrary-code sandbox. Prompt/adapter/data hashes predate generation, but task selection and later aggregate refinements are exploratory. Public data/test labels, source contamination, hidden provider context, exact hosted checkpoint identity and one-generation uncertainty remain unresolved. Current strongest specialist performance is unverified even where historical predictions were rescored.
