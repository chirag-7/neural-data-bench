# Central status — v0.3, 30 October 2026

## Accomplished

- 114 task–resource pairings in 14 navigational families; original 90 + two 12-entry audits.
- 134 source URLs, prospective bounded extension search log, explicit screening exclusions and admission decisions.
- 114 decentralized task cards with methods, actual worklogs, data descriptions and references, linked through family indexes.
- A new private GitHub repository and category → task dashboard with bar charts, ordered-generation line plots and data downloads.
- C05 real-data audit: five original Spikefinder preparations, three unchanged generated estimators, locally run OASIS/default baseline, archived specialist predictions and preserved failures.
- M04 synthetic audit: 24 independent simulated Q-learning agents, three generated estimators, canonical local multistart MLE and post-hoc objective-aligned posterior reference.
- Central scalar/per-unit measurements, predictions, hashes, model-generation metadata, execution records and derived descriptive statistics.
- Scientific validation of pinned scorer equivalence, published archive cell values, original pilot reproduction, likelihood hand fixture and optimization convergence.

## Not accomplished

This is not a finished all-domain experiment or a completed systematic review. There are 2 tasks with measured slices, 96 mapped candidates awaiting data/rights/scorer/baseline validation and 16 deferred from lightweight execution. Only one biological benchmark is evaluated; five preparations do not provide five independent neuroscience domains. No open-weight, direct multimodal, world or neuroscience-pretrained model is evaluated. Current global best performance is unverified for every entry. No scores are inferred from literature fragments or missing runs.

Independent human domain review, complete database screening, cohort deduplication, additional model-generation replicates, biological-unit uncertainty, contamination-resistant cases and matched current specialist budgets remain necessary for paper-level broad claims.

## Execution log and deviations

Protocols were committed before evaluation; this was exploratory version control, not external preregistration. C05 preparation 1 had been seen in the prior pilot. Preparations 2–5 test the same code without reprompting; prompt dimensions refer to preparation 1. GPT-5.6 C05 exceeded the requested code length, so strict-format summaries exclude its five reuse slices. Approximate memory was not enforced. One initial phase-2 launch lacked the project scientific Python path and stopped before any model computation; it was relaunched with unchanged submissions and the existing dependency directory. Numerical model scores reproduce the original pilot on preparation 1.

Four archived reference attempts are unusable under the complete-target contract: Speiser preparations 2 and 5 have shape mismatch, Speiser 4 and Deneux 5 have nonfinite labeled predictions. They remain failures in central records. Complete historical reference availability is 4/3/4/3/2; “best available archive” does not mean strongest current specialist.

After observing that M04’s three programs implement posterior medians, an independent posterior-median reference was added in a dated post-hoc amendment. Original MLE and model scores were retained. Local optimizer convergence is not certification of the global optimum. Near-identical M04 model differences are numerical quadrature effects, not a capability trend. Luna generation had begun before the user removed it; it was never executed/scored and is excluded from this release.
