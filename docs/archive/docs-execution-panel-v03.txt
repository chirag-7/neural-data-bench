# Next multi-domain panel: candidate admission order

This is a concrete execution queue, **not an assertion that these datasets/rights/scorers are validated**. The first two exploratory tasks are already measured. Each additional candidate must pass its task-card admission gates or be deferred with a reason. Freeze one endpoint and manageable slice before model generation. Aim for scientific diversity rather than a maximal benchmark count.

| Perspective | Candidate | First bounded endpoint | Main admission check |
|---|---|---|---|
| Optical signal inference | [C05](../benchmarks/C/C05/README.md) | Original five-preparation processed-trace inference | Measured exploratory audit; next need independent generations and comparable modern specialist |
| Cognitive modeling | [M04](../benchmarks/M/M04/README.md) | Known-equation parameter recovery | Measured synthetic sanity check; next add model misspecification and real-data held-out prediction |
| Behavior measurement | [A01](../benchmarks/A/A01/README.md) | One IBL pupil/paw keypoint split | Species/session grouping, pixel coordinate conventions, generic-vs-animal pretraining |

This queue intentionally includes different ground truths and operations. It remains insufficient for all subfields: acoustic behavior, spatial molecular assays, intervention response, sleep microevents, source localization and embodied control need additional anchors after the initial panel. A strict low-resource release may need to defer imaging/control tasks; report the resulting coverage loss rather than quietly replacing them with easier unrelated tasks.

For each admitted endpoint, use at least one simple conventional baseline and a strong current specialist reproduced on the exact slice. Choose model families suited to the input, and distinguish T0/T1/T2/T3/T4. Do not reuse T3 code synthesis as evidence for all model modalities. Establish affordable repeated-generation and grouping-aware uncertainty plans before claiming broad trends. No execution budget or end date is promised by this queue.
