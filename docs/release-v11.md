# Preview 0.11: one audited batch across seven lab tasks

The integrated 0.11 ledger contains **30 measured task IDs across 14 families, 37 slices/model and 111 first-submission execution attempts: 107 numerically valid outputs and 4 execution failures**. Strict-format-valid counts are 28/36/36 for GPT-5.6/GPT-6/GPT-6.1, out of 37 attempts each. There are 90 first-submission programs; six separate H02 follow-up programs give 96 overall. The 208 model/reference records contain 200 unique central prediction/output manifests; seven H02 follow-up outputs give 207 across both panels. Binary codec payloads are additional artifacts, not attempts. The active map has 92 entries: 30 measured, 33 pending validation, 29 deferred; 62 remain unrun. 22 others are archived, 114 historical entries preserved. 227 associated source URLs are an inventory, not 227 fully reviewed papers.

This release replaces one-task-at-a-time publication with parallel source preparation/model generation, task-specific freezes, and one audited integration. It adds real acoustic annotation, calcium/electrical inference, population forecasting, molecular fraction calibration, optotagged cell classes, event compression, and an explicitly synthetic motion diagnostic. ## What the results establish

Compliant generated programs improve on the declared local reference in several bounded endpoints. These are useful procedure-construction demonstrations. They do not establish native multimodal perception or current global best. Reference implementations range from original Spikepack/SpikeInterface numerical routines and default OASIS to conventional shrinkage/classification and an analytically fitted NLinear architecture; their training/search histories are unequal. A fixed conventional reference is not automatically the strongest neuroscience specialist.

C06's primary correlation 0.846579–0.867592 exceeds default OASIS0.715517, but severe count-scale errors remain. One test neuron's signed relative count bias is 7.489847, 24.107274 and 16.543687 for the three models, versus 201.679029 for OASIS. Reporting only the high correlation would overstate quantitative spike recovery. K05 tests supervised calibration of three orthogonal marker-positive fractions; anonymous expression columns and adjacent-section measurements do not establish full cellular deconvolution. A15's approximately 0.99 event F1 uses one held-out bird, curated bouts and declared 20 msboundary tolerance; boundaries originally had algorithmic segmentation assistance. B03 is synthetic. E06 main/taxis outcomes are dependent one-brain slices. B08 uses the same monkey recordings as G01 and intentionally permits timing loss.

## Source, scope and audit

**B03.** Fully synthetic SpikeInterface drifting-voltage simulations: 4 train/4 held-out seeds, 90s each. Processed detected/localized peak-count rasters and rigid imposed displacement; not in-vivo motion or full DREDge reproduction. Official decentralized-registration routines are used on this custom front end. No held-out sign/scale/time alignment; only additive translation gauge removed. [Protocol](../experiments/B03/protocol.md).

**B08.** Alternate FALCON M2 source after original IBL metadata access returned 403: 7 whole calibration recordings, 1,052,545 events, one monkey; same source as G01. At most 50 us/event timing error, exact labels/order; intentionally timing-lossy. Spikepack 0.1.0 is original-code local execution on another source, not its original IBL benchmark. Two heapq whitelist failures are retained; exact exclusion was ambiguous in broad prompt utility wording. [Protocol](../experiments/B08/protocol.md).

**C06.** All 15 CASCADE DS04 OGB1 zebrafish neurons/45 recordings; 7 neurons/21 train recordings from 2 fish, 8 neurons/24 test recordings from 2 other fish. Custom native-rate 200 ms-smoothed count/Pearson endpoint, not paper benchmark. Default AR1 OASIS with training count scaling; public CASCADE global weights include held-out source and are not used. Source repository GPL3; no separate data-specific license declaration located, so raw arrays stay local. [Protocol](../experiments/C06/protocol.md).

**E06.** One original ZAPBench zebrafish brain/session, 256 response-independently selected neurons. Main 43 temporal-tail forecast windows and prespecified 12 unseen-taxis windows reuse the same program. Causal 64 frame history to 32 frame future, not free-running rollout, cross-animal transfer or full whole-brain leaderboard. NLinear architecture is analytical ridge 1 local optimization, not official published weights/training. Slices are dependent. [Protocol](../experiments/E06/protocol.md).

**K05.** Executed deviation: supervised anonymous bulk-expression-to-three Circle-panel IF/RNAScope fraction calibration, not full reference-only deconvolution. 5 train/3 test donors, 7/4 blocks, 39/24 bulk samples; technical replicates share block truth. Native logCPM2000 selected numeric columns; despite frozen protocol feature-ID wording, no gene IDs passed to either procedure. Source Confidence OK/High; targets are original prop, never prop_sn or adjusted compositional fractions. Three fractions need not sum 1. [Protocol](../experiments/K05/protocol.md).

**K06.** Allen-only optotagged PV/SST classes: 136 train/71 test cells in 11/5 disjoint mice. Six waveform scalars plus 81 normalized waveform samples. No genotype, IDs, putative types, opto responses or firing/ACG/ISI predictors. Binary genetic cohort task, not full molecular taxonomy; only 5 PV mice in source, brain-area metadata incomplete. Allen research/noncommercial terms retained separately from CellExplorer code BSD license. [Protocol](../experiments/K06/protocol.md).

**A15.** Numeric 32 kHz audio code synthesis, not native multimodal perception. 60 whole recordings from 3 training birds, 20 from 1 held-out bird; 1519 held-out events. Boundaries amplitude-segmented then manually labeled; incomplete contact-call coverage, curated song bouts, source float16 quantization. DAS CSV milliseconds were mislabeled seconds; all 90 same-record original annotations independently establish 1/1000 conversion. Fixed 20 ms onset/max 20 ms-or 20% offset tolerance; not paper sample-wise metric. [Protocol](../experiments/A15/protocol.md).
